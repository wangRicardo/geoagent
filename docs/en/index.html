Up and Running in Three Minutes

Install and go. Extending it takes one Python function with a docstring.

terminal 
# Install
pip install geoagent-ml[all]

# Start a chat in any folder (codex-style workspace)
ricardo chat D:\research\survey-A

# Hot-swap provider / model / thinking effort in chat
/provider deepseek    /model deepseek-reasoner    /thinking high

# Ask the agent to write a report and compile it
"Write a phase-picking experiment report and compile it to PDF"
my_tool.py — your first domain tool 
from geoagent import registry

@registry.register(category="geophysics")
def nmo_velocity(t0_ms: float, vrms_ms: float, offset_m: float) -> str:
    """Compute NMO stretch for a given offset from T0 and Vrms."""
    t = (t0_ms**2 + (offset_m / vrms_ms)**2 * 1e6) ** 0.5
    return f"NMO moveout: {t - t0_ms:.2f} ms @ offset={offset_m} m"

# Saved — the LLM can call nmo_velocity immediately. Zero glue code.
